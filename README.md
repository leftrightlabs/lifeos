# LifeOS

Personal command center dashboard for Gretchen Cawthon. Deployed on Railway.

## Local dev

```bash
npm install
npm run dev
```

Visit `http://localhost:3000`

## Deploy

Push to `main` — Railway auto-deploys from GitHub.

## Env vars

| Var | Required | Notes |
|---|---|---|
| `PORT` | No | Set by Railway automatically |

More will be added as data integrations come online (Day 2+).
